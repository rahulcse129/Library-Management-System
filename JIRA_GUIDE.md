# Jira Scrum Guide

## 1. Create the Scrum project

1. Sign in to Jira.
2. Select **Projects** and choose **Create project**.
3. Select the **Scrum** template.
4. Enter **Library Management System** as the project name.
5. Select **Create project**.

## 2. Create the user stories

For each story:

1. Select **Issues** → **Create**.
2. Set **Issue type** to **Story**.
3. Enter the summary and description from the table.
4. Set the priority and story points.
5. Select **Create**.

| Story | Summary | Description | Priority | Story points |
|---|---|---|---|---:|
| 1 | Book Search | As a library member, I want to search for books by title so that I can find books easily. | High | 3 |
| 2 | Issue/Return Book | As a library member, I want to issue and return books so that I can borrow library resources. | High | 5 |
| 3 | Member Registration | As a new user, I want to register an account so that I can access library services. | Highest | 3 |

## 3. Move stories through the workflow

1. Open the project's Scrum board.
2. Find the story in **To Do**.
3. Drag it to **In Progress** when work begins.
4. Drag it to **Done** after the work is complete.
5. Repeat these steps for all three stories.

If the project uses a different field name, use **Story points** or
**Story point estimate** for the estimate.
